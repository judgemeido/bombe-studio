# 信号实验室：教学与实现说明

## 教学范围

第一章保留 Bombe 整机与五系统拆解。第二章从 108 个鼓轮缩减到一组三转子置换回路，包含接线板、从右到左的 III→II→I、B 反射器，以及 I→II→III 的返回路径。它让一个按键真正得到一个输出，并能逐段解释同一次计算。

这一单元采用 Enigma 的接线与转位规则解释 Bombe 模拟转子关系的背景。Bombe 整机还依赖菜单电路、对角板和候选设置检查；本页没有实现这些搜索流程。三个鼓轮并排、触点尺寸、布线空间和抽出距离均为教学示意，不能当作实物内部结构或加工尺寸。

## 一次可复现的教学过程

1. 打开 `#/lab/drums`，点击“复位”，得到轮位 AAA、无接线。
2. 按 A。机器先转到 AAB，然后将 A 转为 B。点击“下一段”或九张步骤卡，查看各次置换。
3. 点击“重播信号”，它只回放这一条路径，轮位和记录不会再次改变。
4. 再按 A，轮位变为 AAC，输出 D。连续五个 A 的结果是 BDZGO。
5. 从“记录与验证”打开记录，再点击“验证当前轮位的互易性”，当前转换 A→D 可以沿同一轮位得到 D→A。再次按键会先转位，因此不能直接用再次按 D 代替静态验证。
6. 进入接线局部，点击 A、B 两个插孔，或从“轮位与接线”打开端点菜单接入 A↔B。输入进入接线板时互换，回到接线板时再次按同一规则互换。拔下恢复原样通过。
7. 展开触点结构、拖动观察鼓轮背部固定接点；缩放按钮与恢复视角可调整观察范围。

系统减少动态效果时直接呈现计算结果；仍可点击任意一段逐步阅读。画布/页面获得焦点时，字母键输入，右方向键逐段，空格播放或暂停；原生表单和按钮保留各自键盘行为。

## 一屏界面与信息层级

默认主界面用五步指引说明实验目的，并带领用户观察模型、输入字母、查看输出。桌面为模型加侧边控制台，手机将结果与键盘并排；指引位于模型上方，九段路径固定在实验台下方。主页面采用视口高度的三行网格，中央区域允许收缩，模型通过 ResizeObserver 与包围盒构图适应剩余空间。

大幅标语、装饰背景字、重复边框和常驻教学卡已移除。深绿色仅用于输入/输出区，金色用于建议的 A 键、当前按键与当前步骤；经过的信号路径使用独立的透明材质，当前段保持明亮，对应部件标注同步强调。共享材质不在每帧修改透明度；尾迹材质由模型统一持有并释放。

“轮位与接线”“完整指引”“记录与验证”使用原生 dialog。打开时暂停信号，保留焦点约束、Escape 与关闭后的焦点恢复。点击鼓轮也打开对应轮位；点击两个插孔仍可直接接线。完整指引默认展示五步操作和术语，也可切换转位、接线及整机关系；原转位任务准备后自动关闭并聚焦 A 键，反馈显示在主界面。跳至实验键盘的辅助链接不改动 Hash 路由。

常用桌面和手机视口的核心实验无需页面滚动。高度不足 560 CSS 像素的极矮窗口保留自然滚动，防止浏览器放大或横屏时操作被裁掉；较长说明仅在弹层内部滚动。当前证据见 LAB_GUIDANCE_QA.md；LAB_LAYOUT_QA.md 和 LAB_QA.md 保留前两版的验收历史。

## 默认五步操作指引

`lab-walkthrough.js` 独立持有教学进度和对照结果，调用 `lab.js` 的同一组复位、按键、逐段、设置命令。指引按钮、真实字母键和实际接线共用业务逻辑；教学不另行生成预设答案。

1. 准备：点击“准备实验”回到 AAA、无接线，清除当前记录。若从接线局部开始，回到完整回路。
2. 输入：点击 A 后先转位至 AAB，教学停在信号第 1 段，保留阅读时间。
3. 追踪：每次点击“下一段”前进一段；支持自动播放或底部步骤跳转。到第 9 段才显示输出 B，再进入比较。
4. 比较：不复位再按 A，轮位 AAC、输出 D。当前框说明轮位改变映射；也可直接查看结果，跳过本次动态演示。
5. 接线：打开设置时明确回到 AAA，端点预选 A、C，用户实际点击“接入”。接错其他字母时仍提示更正；接入后再按 A，实际计算输出 Q，并与第一轮的 B 对照。完成后可自由探索。

中途额外按键或修改轮位会让指引回到准备步骤，说明原因；不静默替换用户当前结果。切换自由探索保留模型、设置和记录，恢复指引后需明确点击准备按钮才复位。原先“两次 A”小任务以自由模式运行，避免两个任务同时给出下一步。

模型和输入输出采用 2px 深色框，键盘和信号区采用 1.5px 深色框；当前操作区域增加铜色描边，当前路径步骤采用 2px 铜色框。说明使用实时 DOM 状态，减少动态效果下也可手动逐段阅读。

## 数学与数据边界

轮序从左到右固定为 I、II、III，环位固定 AAA，反射器固定 B。UI 开放一对跳线；纯算法支持不重复的十对跳线。每轮的接线字符串表示 A…Z 的正向输出，反向使用逆置换。

设输入编号为 x、当前轮位为 p、转子置换为 W。正向结果为 `(W[(x+p) mod 26]−p) mod 26`；反向将 W 替换为逆置换。反射器是无自环的成对置换。每次按键先推进快轮；快轮位于缺口时推进中轮，中轮位于缺口时同时推进中轮与慢轮，所以保留双步进。

`traceLetter()` 固定轮位计算，`pressKey()` 先调用 `stepPositions()` 再计算，`encipher()` 批量推进并保留最终轮位。返回值包含输入、输出、三轮位置和九个前后衔接的步骤。界面、说明文字和信号模型都消费这一份结果。

参考配置的两个验证向量为 `AAAAA → BDZGO` 和 `HELLOWORLD → ILBDAAMTAZ`。接线数据和缺口依据 Crypto Museum 的 Enigma wiring/working 资料，链接列在 README。测试还覆盖置换完整性、无自环反射器、九段衔接、固定轮位互易、文本往返及非法端点。

## 模块与状态

| 模块 | 输入与职责 | 对外边界 |
| --- | --- | --- |
| `navigation.js` | Hash 路由、准备回调、激活回调、动态偏好 | `go()`、`current`、`busy`、`dispose()` |
| `lab.js` | 唯一实验状态：轮位、配对、trace、progress、播放、记录、教学任务 | `setActive()`、`setTopic()`、`dispose()` |
| `lab-template.js` / `lab.css` | 实验台结构、视口网格、视觉重点、按需弹层 | 不持有算法或模型状态 |
| `lab-walkthrough.js` | 五步教学状态、对照结果和下一步指引 | 通过回调调用实际实验命令，不访问三维对象 |
| `cipher.js` | 校验字母/轮位/配对、纯置换与步进 | 可直接由 Node 测试或复用于其他 UI |
| `lab-model.js` | 统一 `LAB_DIM`、几何、拾取、接线与九段路径 | 不访问 DOM，不持有教学业务状态 |
| `scene.js` / `framing.js` | 渲染器、灯光环境、轨道相机、包围盒构图 | 与整机共用渲染和相机实现 |

`progress` 为同一次信号的已通过段数，范围 0…9；准备按键时允许短暂小于零以先呈现轮位变化。暂停、逐段和任意步骤选择都修改同一个值。只有新按键调用 `pressKey()`；重播不会重复计算或进位。修改轮位或接线会清除旧路径与记录，避免把不同设置的结果混在一起。记录保留最近 24 次输入。

模型公开 `root`、`pickables`、`setPositions()`、`setConnection()`、`setTrace()`、`setSpread()`、`setTopic()`、`getBounds()`、`getAnchor()`、`pick()`、`update()` 和 `dispose()`。`LAB_DIM` 的半径 1.25、轮距 3.05、26 个触点及端点间距用于展示，数值没有米制实测含义。转动件与固定后接点分组，展开只沿轴向移动转动件，不让三个鼓轮互相穿过。

## 转场与加载

路由为 `#/`、`#/lab/drums`、`#/lab/wiring`。顶部、结构笔记、教学返回链接使用同一事件委托；浏览器历史与直达刷新走同一准备流程。连续请求串行处理，以最后请求为最终页面，避免同时初始化多个教学模型。

加载进度依次为准备 8%、动态导入 26%、建模 52%、材质预热/恢复 78%、就绪 100%。首次进入真实等待 `import()` 和 `renderer.compileAsync()`；返回已经构建的页面恢复原状态。这是准备阶段条，不表示下载字节百分比。

转场开始暂停场景并设置页面 inert，关闭展开的笔记，显示柔和的章节幕布。目标页准备后执行内容入场与幕布揭开，恢复目标页滚动位置，最后将焦点移到标题。减少动态效果时跳过位移、模糊和幕布动画。导入失败显示重新准备/返回整机；重新准备刷新页面，以清除浏览器对失败 ESM 导入的缓存。

## 渲染、资源与扩展

静态几何按父分组与材质合并，保留转动和展开边界。Canvas 生成字母刻度与接线板标签，无远程纹理或 GLB。复用灯光、环境反射与阴影，未引入后处理或游戏引擎。换线与换 trace 时释放旧 TubeGeometry，卸载时释放全部自有几何、材质、纹理、渲染环境、监听和 RAF。

只有当前章节且 document 可见时更新模型与渲染。两章状态在同一文档生命周期中保留；刷新后重置。WebGL 初始化失败时禁用模型操作，保留计算、九段文字与练习；上下文中断时暂停绘制，恢复后重新生成 PMREM 环境目标，避免反射内容丢失造成模型变暗，然后继续绘制。

`npm run build` 输出 ESM 入口与哈希分包，必须部署完整 dist 目录。开发服务将一次成功构建的文件在内存中同步发布，并在本次进程内保留旧哈希分包，让更新前已经打开的第一页仍可稍后载入实验室。开发输出与发布目录相互独立。

新增转子/环位时先扩展纯算法与参考向量，再将 trace 交给模型和界面。新增教学部件时保持几何 API 与 DOM 状态分离；路径端点、标注与相机范围应从同一尺寸定义推导。不要把本单元的 Enigma 运算直接标为完整 Bombe 破译算法。

验收环境是 Windows 本机 Chromium 的桌面视口及触摸设备模拟。没有实测物理手机、Safari/Firefox 或移动 GPU 帧率；绘制调用与资源计数是本机诊断，不代表所有设备性能。
