# 00 战时序章 P3 首页与延迟启动 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 无hash首页和 `#/history` 展示七幕序章；保留 `#/`、实验室和挑战深链，读历史时不下载或创建Three场景。

**Architecture:** 增加轻量入口bootstrap；首页HTML静态携带历史正文和原应用壳，互斥显示。bootstrap仅在首次进入01/02/03时动态导入主应用，之后由统一导航协调四章；原应用初始化改为显式工厂，整机WebGL再推迟到01需要时。历史CSS限定作用域，既有展品/教学CSS保留，避免两套全局字体、body、品牌和章节样式互相污染。

**Tech Stack:** 原生ES模块、HTML/CSS、esbuild分包、node:test/happy-dom；不新增框架或依赖。

**Spec:** [体验方案](../../HISTORY_00_SPEC.md)。P2产品基线 `d80e92e`，七幕预览已交付；本计划待审阅。执行沿用用户选择的子代理实施与逐项复核。

## Global Constraints

- 无hash `/` 与 `#/history` 为00；旧 `#/` 保持01；`#/lab/drums`、`#/lab/wiring`、`#/challenge` 直接访问/刷新不得先跳00。未知路由沿用旧回退01。
- 四章导航显示00/01/02/03，品牌回00；历史内章节使用普通锚点，不被当成01路由，不破坏分享与返回。
- 保留七幕正文、图注与无JS可读性、减少动画、图片超时回退；正文不能为初始化WebGL而等待。
- 保留解密引擎、随机题目规则、3D结构与教学行为；不顺便重写其业务逻辑。
- 初始00不导入Three、stage、product、lab、challenge；首次进入交互章才载入交互依赖，01整机只初始化一次；后续往返保留拆解状态。
- 同一时刻只有活动页可见/可聚焦；加载失败可重试，快速切页最后请求胜出。不建立第二套互相竞争的hash监听器。
- 不将A2肖像未决标成已解决；不额外搜索或加入未经授权图片。

## 文件职责与边界

- 新增 `src/routes.js`：纯四章路由合同，从现有navigation解耦供bootstrap及主应用共用。
- 新增 `src/bootstrap.js`：轻入口、动态应用工厂加载缓存/重试、历史控制器生命周期。
- `src/main.js`：导出 `createApplication({ initialRoute, historyPage })` 工厂返回 `{ go(route), dispose() }`；消除模块导入即初始化。接入四章导航并抽出 `ensureExhibit()`，延迟整机创建。
- `src/navigation.js`：复用routes导出，四章metadata/滚动/焦点/当前项；增加历史准备与直接首章激活，取消初始默认exhibit假设。
- `index.html`、`history-preview.html`、`build.mjs`：历史静态正文保持单一来源；build输出合成首页、独立预览保留。开发服务也从同一合成函数生成index，不要求手抄两份正文。
- 新增 `page-shell.mjs`：纯HTML合成，消费现有应用壳与历史预览，给应用body内容包 `#application-shell`，历史正文包 `#history-page`；不得使用正则任意重写未限定内容，采用明确模板标记分界。
- `history-preview.css` 与 `styles.css`：历史选择器限制到历史根/历史body模式；应用样式在00未激活，切页后正确恢复。独立预览继续使用原样式入口。
- `tests/routes.test.mjs`、`tests/bootstrap.test.mjs`、`tests/navigation.test.mjs`、`tests/page-shell.test.mjs`：路由、并发/重试、DOM可见性、资源/静态内容合同；原66项保留。
- `docs/HISTORY_00_P3_QA.md`、`output/history-00-p3/`：回归矩阵、截图、网络依赖检查和独立复核记录。

## Task 1：路由合同和静态首页合成

**接口：** `parseRoute(hash)` / `routeKey(route)` 迁至routes并由navigation重导出。route.page可为history/exhibit/lab/challenge；topic仍drums/wiring。历史章节ID白名单来自七幕及lifeline-context/sources，解析为history。`renderHome({ appHtml, historyHtml }) -> string` 位于page-shell.mjs。

- [ ] 测试先行：无hash/history→history，旧四条深链逐一往返，未知→exhibit，历史白名单锚点→history；各路由键不把无hash历史写成旧 `#/`。运行观察失败。
- [ ] 为HTML合成写失败合同：七幕正文恰一份、ID不重复、两个互斥根、原对话框/过渡层可定位；只引用bootstrap轻入口、不直接app/historyPreview双启动；生产/开发资源路径均存在。明确历史根包含自己的页头/页尾，不复制另一份导航活动状态。
- [ ] 以显式标记定义app壳和历史正文边界，完成纯合成函数；build/dev调用它，独立preview仍可打开。页面初始为历史可读、应用hidden/inert；深链在bootstrap激活前不等待历史图像。
- [ ] 限定历史样式作用域，避免通用 `.brand`、`.chapter-nav`、`body`、`:root`、`a`污染应用；保留独立预览兼容。添加四章入口、品牌00链接，历史普通锚点不冒充应用data-page。
- [ ] 聚焦测试/build与独立复核通过后提交；不在该任务启动3D或修改密码规则。

## Task 2：轻入口与导航生命周期

**接口：** `createBootstrap({ root, loadApplication, motion }) -> { dispose() }`，root为document或页面壳，loadApplication默认动态import main；该依赖允许测试注入。主应用工厂 `createApplication({initialRoute,historyPage})` 与统一导航共用四章合同。

- [ ] TDD模拟loadApplication：初始history/章节锚点不调用；初始lab/challenge直接载入对应路由；快速连续点击仅最终路由激活；import拒绝后可重试；同一成功模块/工厂只创建一次。先观察失败。
- [ ] 实现bootstrap历史首屏图像与场景控制器挂载，不导入main/Three；第一次交互请求载入main工厂，交接路由后不再保留竞争监听器。历史/应用切换由统一导航负责。
- [ ] navigation增加history章标题、焦点目标、独立scroll记录；history激活隐藏应用并恢复历史控制器，离开销毁观察器与载入计时。活动历史内部锚点保留原生行为与hash；返回00恢复读位，不强制跳首屏。
- [ ] 测试注入prepare/activate覆盖快速请求、失败重试、title/aria-current、页hidden/inert、焦点与滚动；原路由测试继续通过。检查modified click不被劫持。
- [ ] pagehide/pageshow缓存恢复覆盖both历史与应用，dispose可重复；旧异步回调不能重建已销毁应用。独立复核后提交。

## Task 3：主应用显式工厂与整机按需初始化

**接口：** main不再顶层创建运行时；`createApplication`负责原有控件与导航；`ensureExhibit() -> Promise<void>` 缓存成功初始化，失败释放部分资源并允许重试。图片/scene历史控制器使用create函数，禁止再导入auto-mount入口制造双挂载。

- [ ] 先写fixture/可注入初始化测试：初始history不创建应用；初始lab/challenge不createStage/createProduct；第一次exhibit只创建一次、连续请求共享promise；初始化失败回收并可重试。观察失败再重构。
- [ ] 把原main顶层状态/监听/RAF封装为工厂，保留lab/challenge动态模块与原设置；仅ensureExhibit创建stage/product/raycaster。01激活时resize/frameCamera，非活动章不渲染整机。
- [ ] 原有部件选择、拆解、相机、context lost/restored和dispose绑定到成功创建的运行时；创建失败保留现有可读错误说明；不因延迟创建让按钮访问未定义对象。
- [ ] 将四章根列表集中，避免遗留三章循环漏history；隐藏页inert、skip-link与品牌导航正确。保留挑战每次重新进入换题的既有规则，不在00锚点变化时换题。
- [ ] 全测试/build通过，独立审核资源生命周期/重复初始化/旧业务不变后提交。Task2与本任务共享main/navigation写集，必须顺序交接，不并行修改这些文件。
