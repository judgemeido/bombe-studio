# 00 战时序章 P2 七幕叙事 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已审阅的双段视觉样稿扩展为可连续阅读的七幕历史序章，并交付双端浏览器证据；本阶段仍为独立预览，不替换首页。

**Architecture:** 扩展现有 `history-preview.html` 与 CSS，正文保持初始语义 HTML；把新增的章节观察与图解增强放在独立控制器，复用已测试的图片载入控制器。没有新框架、没有新的密码模拟器；最终进入01/02/03仍链接既有主应用。

**Tech Stack:** HTML / CSS / 原生 JavaScript；IntersectionObserver；esbuild；node:test、happy-dom；真实浏览器。

**Spec:** [体验方案](../../HISTORY_00_SPEC.md)、[七幕文案](../../HISTORY_00_COPY.md)、[来源](../../HISTORY_00_SOURCES.md)。P1 基线 `ac28651`，执行方式保留用户选择：子代理实施、逐项复核。本计划待用户审阅，尚未授权执行。

## Global Constraints

- 保留深海蓝 `#142633`、档案白 `#E4E7E2`、机械绿 `#52614D`、黄铜 `#B69A67`；普通文字对比度至少4.5:1。
- 七幕顺序为海运背景、截获、波兰先驱、图灵、Bombe约束、情报链条、进入展览。正文采用已确认COPY；补充史料只做有出处的纠错，不扩写戏剧化故事。
- 不随机生成假解密，不把 Bombe 写成直接输出可靠明文；不把图灵写成唯一贡献者，不混淆 Lorenz/Colossus/Enigma。
- 图片许可未解决就保留明确状态；不使用生成头像或未经授权照片。A1本地护航照片继续使用，A2肖像未决不阻止图解及叙事开发，但不宣称人物实拍已完成。
- 全部正文、标题、图注和按钮从初始HTML可读；不劫持滚动、不自动播放声音；无JS、无观察器和减少动画时都能阅读。
- 不修改 `index.html`、`src/main.js`、`src/navigation.js`、密码引擎和挑战规则。默认首页与WebGL延迟初始化属于P3。
- 保持chrome110 / firefox110 / safari16目标，不新增依赖。资源在本地，图像预留尺寸。

## Review Focus

1. 多章节同时进入视口：选取当前阅读章节必须稳定，不能由回调数组顺序决定。（Task2）
2. 回退/重复挂载：pagehide后断开观察器，缓存恢复只挂载一套，旧回调不能修改索引。（Task2）
3. 无JS/无IO/reduced-motion：不能把文字或关键流程隐藏，索引仍为可用锚点。（Task1、2）
4. 长中文、外国姓名与窄屏：390px下无横向溢出；图解标签可读、不需要横向拖拽。（Task3）
5. 引用与图像状态：S6取不到就明确未决，A2不能因扩展到七幕而变成“已授权”。（Task1、3）

## Task 1：完整七幕静态内容与叙事图解

**接口：** 七个且仅七个 `[data-history-scene]`，按阅读顺序ID为 `lifeline / intercept / pioneers / turing / constraints / intelligence / onward`；首屏包含在lifeline幕内。章节索引位于 `nav[aria-label="历史章节"]`，使用 `[data-scene-link]` 与对应hash。主应用链接固定 `/#/`、`/#/lab/drums`、`/#/challenge`。

- [ ] 先修改静态合同测试：断言七个有唯一ID的场景、七个索引锚点均有目标、三位波兰先驱姓名、1932/1939共享背景、Welchman与BTM、候选检查、完整情报链条、末幕三个实际链接；断言不再有“两幕/暂时省略”提示。运行聚焦测试，观察旧双幕实现失败。
- [ ] 补核S6：使用可访问的战争史机构来源核对波兰入侵、英法宣战、英国海运依赖和大西洋战役背景；逐条记录已读链接与支撑论断。访问失败不得绕过安全提示或当成阅读成功。不为取得图片而无限搜索；肖像仍未决则保留占位说明。
- [ ] 按COPY补入01的战争前因与补给主文、02/03/05/06/07的主文和必要展开内容；保留P1首屏/图灵构图，删除省略过渡。页面标记改为「七幕预览」，不称已上线首页；页尾保留来源与教学简化说明。
- [ ] 新增原创SVG：截获关系、1932→1939知识接力、crib→约束→排除→检查、情报链条、Bombe轮廓。图解均有caption与简化边界，SVG无外部脚本/foreignObject；不显示随机密文转换。03采用姓名与资料流，05采用逻辑环，06采用流程，不做五张重复卡片。
- [ ] CSS以独立场景类组织；桌面允许局部sticky，小屏改纵向；图解小屏需重排而非缩到字不可读。章节索引有焦点样式，当前章节标记不依赖颜色。修正照片上小字底色，避免可变图像背景造成不可控对比度。
- [ ] 测试验证全部静态图解资源存在、来源链接可定位、声明未决项仍保留；执行聚焦静态测试与build，再交独立代理复核并修正。通过后提交。

## Task 2：逐幕激活与图解渐进增强

**接口：** `createHistoryScenes(root, { motion, Observer = root.ownerDocument.defaultView.IntersectionObserver }) -> { destroy() }`，位于 `src/history-scenes.js`。消费Task1 DOM；活动场景添加 `is-current`，对应索引设 `aria-current="location"`；仅已阅读图解添加 `is-revealed`，正文不隐藏。

- [ ] 测试先行：用可控Observer测试进入/离开、多entry、乱序entry、所有场景离开、销毁后旧回调、重复destroy、缺失Observer、reduced-motion及设置运行中变化。预期：最多一个当前标记，无匹配场景可清空，不滚动不抢焦点；增强类不删除正文。运行观察失败。
- [ ] 实现稳定规则：维护各场景交叉状态；同时可见时优先选择距离视口顶部25%阅读线最近的场景，距离相同按DOM顺序；不要直接取最后一个entry。导航不写hash、不改原生返回栈。destroy清理Observer、motion监听与自身增强状态，不操作其他页面。
- [ ] 无Observer时保留锚点索引、不伪造滚动进度；减少动画时图解立即完整显示，章节索引可正常工作；变化时同步状态，禁止通过移除内容实现“逐步加载”。
- [ ] 图解路径仅在is-revealed后做一次有限描线/遮罩；CSS默认完整可见，由脚本标注增强后才设置局部图解初态；正文永不opacity0。约束步骤的静态全部标签始终存在，不冒充真实搜索结果。
- [ ] 接入现有自动挂载包装：pagehide同时销毁加载与章节控制器，persisted pageshow恢复且不重复监听。保留既有 `createHistoryPreview` API测试；新增集成测试验证两控制器都只恢复一次。
- [ ] 执行场景测试、加载测试、静态测试；独立复核生命周期和回退，再提交。若Task1静态尚在复核，可先用测试fixture实现本控制器；HTML/CSS由Task1独占，避免写集重叠。
