## 1. 体验目标与边界

在进入机器之前，让读者理解三个问题：为什么需要破解通信、突破来自哪些人的接力、Bombe 实际解决什么问题。不是二战全史，也不是图灵个人英雄传。

主线建议阅读 4–6 分钟（设计估计，待真人测试）；人物和技术细节可展开。所有入口始终可跳过序章。此次不重写 Enigma 引擎、不新增一套 Bombe 搜索模拟器、不改挑战关卡规则。

## 2. 艺术指导：深海上的档案

保留「译码档案」身份，以数字博物馆而非游戏开场呈现。

| 层次 | 规范 |
| --- | --- |
| 深海底色 | `#142633`，首屏、海洋、机械收束场景 |
| 档案纸 | `#E4E7E2`，长段正文与人物场景 |
| 机械绿 | `#52614D`，逻辑线和小面积强调 |
| 黄铜 | `#B69A67`，章节号、细线、索引，不作为小字号正文默认色 |
| 字体 | 中文衬线大标题、无衬线正文、等宽日期与编码；先用系统字体栈，外部字体须另核许可 |
| 影像 | 黑白历史照片，保留档案感；不使用生成图冒充历史记录 |

正文颜色逐组合测试 WCAG AA：普通文字至少 4.5:1，大字与必要图形至少 3:1。金色、灰绿不能因“高级感”牺牲对比度。正文建议 17–19px、行高 1.8；桌面正文约 28–36 汉字宽。

避免：七张同构卡片、紫色霓虹、无意义粒子、每段都上浮淡入、强制逐字打字、全程黏性滚动、图灵头像被装饰线遮挡。

## 3. 七幕分镜

| 幕 | 画面与排版 | 滚动中的变化 | 完成后读者应理解 |
| --- | --- | --- | --- |
| 01 海上生命线 | 大幅护航照片；日期在左，正文偏右；原创大西洋示意图 | 海上航线从西向东显现，时间轴推进 | 海运补给与军事通信为什么重要 |

| 03 突破早于战争 | 三位波兰数学家的姓名大字、1932→1939资料接力图 | 线索先连到法国和英国，再进入布莱切利园 | 英国工作并非从零开始 |

每幕必须有自己的构图；03 不强求人物照片，用排版和原创资料流图也能保持史实准确。人物主视觉的真实肖像授权仍是待解决事项，不能用骨架占位图宣称图文设计已交付。

## 4. “HTML 流式”的实现定义

采用**语义 HTML + 分幕渐进呈现**。当前是静态 esbuild 网站，不额外引入服务器分块传输；此处“流式”指阅读体验，不冒称 HTTP streaming 或 AI 实时生成。

- 标题、七幕正文、链接、图注在初始 HTML 中存在，脚本失效时仍能阅读。
- 浏览器自然渐进解析文档；图像按需加载；脚本只增强构图和动画。
- 首屏和图片预留比例，避免一边滚一边追加内容造成高度跳变。
- IntersectionObserver 管理场景激活，WAAPI/CSS 管理遮罩与路径；CSS scroll timeline 只做能力检测后的增强，失败则回退。
- 不用全页 opacity:0 等待 JavaScript；增强失败不能让文字消失。
- 图片不是“最后才显示的附件”：每幕先安排真实影像或有叙事作用的原创图解。

### 载入状态

静态首屏先显示标题与跳过入口。可在小型档案索引上循环扫描线，显示真实的「正在准备首屏影像」状态；图像 decode 成功后退出，不设假百分比或强制最短等待。

- 正文不等全部图片、字体或 Three.js 就绪。
- 首屏图像失败或等待超过 3 秒：结束等待状态，显示可读底色和「影像暂未载入，正文仍可阅读」。3 秒是体验超时，不是加载百分比。
- 切走页面时取消计时器、观察器与动画；晚到的图片不能夺回焦点或切换路由。
- `aria-live="polite"` 只播报状态变化，不反复播报扫描动效。
- 页面可马上跳过，载入层不截获全屏键盘或滚动。

## 6. 手机、无障碍和资源规则

- 桌面只在适合的 01/04/05 使用局部 sticky；小屏改为自然纵向图文，读序与 DOM 一致。
- 不劫持滚轮、无自动翻页、无强制横向滑动、无自动播放音频。
- `prefers-reduced-motion`：关闭视差、描边与扫描位移，全部内容立即可读；允许静态当前章节标记。
- 图像有尺寸、caption、来源链接与有意义的 alt；纯装饰 SVG 对辅助技术隐藏。
- 采用响应式本地图像和后续画面 lazy load，首屏关键图不 lazy；素材定稿后才确定压缩尺寸和预算。
- 图片不可拉伸超过有效分辨率；1200px 档案照可嵌入版式，不宜作为 4K 全屏近景。
- 不热链外站图片；生产资源必须有落盘文件、许可登记、归属说明；链接到来源不等于授权。

## 7. 分阶段验收

1. **P0（本次）**：审阅文案、史实边界、分镜；确认仍未解决的素材项。
2. **P1**：制作首屏 + 图灵两段桌面/手机视觉样稿。真实肖像若未获准，仅可标示素材待定，不冒充完成稿。
3. **P2**：七幕 HTML、图像图解与渐进增强；关闭 JS、图片失败、减少动画也能阅读。
4. **P3**：00 默认路由、01 延迟初始化、静态资源构建与开发服务支持。
5. **P4**：真实浏览器检查 1440/390px、键盘、返回/刷新/深链、慢资源/失败、移动端滚动；既有单元测试与 build 全过。

后续验收不能只看动画截图：00→01→02→03、旧 `#/`、直接刷新 lab/challenge、重复进出不重复初始化都需检查。若展示真实加密转换，必须绑定既有引擎并有可复现设置和测试向量，禁止视觉随机字母伪装正确解密。

## 8. 研究采用与未决事项

已参考 frontend-design 的构图与避免模板化原则、three-product-studio 的主视觉/渐进加载思路、MDN 的滚动动画能力与回退策略。史实和图片权利以来源登记为准，不因视觉效果倒推史实。
