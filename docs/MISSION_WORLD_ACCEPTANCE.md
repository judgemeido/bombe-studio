# 04 连通楼层与设备重构验收

日期：2026-10-20（Asia/Shanghai）。

## 实现

- 七个工作区改为同一连续楼层：五个前排房间、南侧公共走廊、两个后排房间，12 条显式连接。门洞与实际墙体、家具避让采用同一布局定义。
- 扩大工作区并重设七个近景镜头；增加可拖动的楼层全景。地图、交接近景剖切前排立面，返回全景恢复；房间按钮、地点说明、设备读数与手动观察保持一致。
- 重建桌腿、围板、抽屉、椅背、柜门、电话拨盘与卷线、灯具、窗框、记录墙、放大镜、对齐纸框、海图网格/岸线/路线、封存箱与维护车。
- 机房包含两组完整 108 鼓轮 Bombe，保留原 27 鼓轮教学校验器；档案、机房和分析核验桌拥有可同步的 Enigma。
- 修正 15 节拍镜头的房间映射与入场终点；手动镜头切换使用固定时间，避免低帧率导致切换拖延。保留原密码运算、任务状态机与单一 canvas。
