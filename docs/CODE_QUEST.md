# 第三章：小小解密员

入口 `#/challenge`。顶部“03 解密挑战”和第二章右上角“试试六关解密”均可进入，使用原有章节转场和真实准备阶段加载条。

## 六关如何教

| 关卡 | 孩子做什么 | 模型与算法 |
| --- | --- | --- |
| 1 认出小帮手 | 根据部件的本领，点击模型、模型标签或答案卡 | 全回路；真实拾取区分鼓轮、反射器和接线板 |
| 2 跳线换朋友 | 让一个字母经过接线板，选择出口 | 放大接线局部；`plugboard` 计算双向互换，也抽取未接线字母保持原样的题 |
| 3 鼓轮走一步 | 从起点按 1 或 2 次字母，读三字母轮位 | `pressKey` 实际转位；只抽取无需解释进位的起点，包含 Z→A |
| 4 跟着亮线走 | 输入一个字母，沿九段亮线读出输出 | 三只鼓轮、反射器、接线板；`pressKey`，可播放、暂停或逐段前进 |
| 5 信号原路回 | 看已知 X→Y，锁住轮位，把 Y 送回 | `traceLetter` 固定轮位验证互易；明确区别于再次按键 |
| 6 救出小消息 | 按任务卡调三轮起点、接一对字母，逐字输入三字母密文，再选择消息含义 | `encipher` 出题；`pressKey` 每次解一个字母，轮位连续变化，不在字母之间复位 |

每关有三步操作、可展开提示、即时解释和重试。完成当前关才开放下一关，不倒计时、不扣分。最后获得六枚对应知识的印章。词卡同时显示字母和中文，孩子无需记忆英文词义或转子接线表。

## 抽题和排列组合

`src/challenge-engine.js` 是不依赖 DOM/Three.js 的纯模块。

1. 每次进入第三章、刷新第三章或点击“换一套题”，使用 `crypto.getRandomValues` 生成新种子。
2. 种子进入确定性伪随机序列。保留 seed 与最近题目签名即可复现同一套参数和选项顺序，方便排查课堂问题。
3. 按六个知识层级分层抽题，保持难度递进。第一关有 6 条部件题；接线和追踪各有 3 种题干，转位有 1/2 次两种模式，互易有 2 种题干；最终词库包含 20 个三字母词及中文含义。
4. 把题干与输入字母、轮位、合法的一对接线、按键次数或消息词组合。干扰项去重，排除正确答案，再与正确答案一起进行 Fisher–Yates 洗牌。末关从其他词卡抽取 3 个干扰项。
5. 正确答案由同一个 `cipher.js` 回路计算，不维护另一份硬编码答案表。每题恰好一项正确；部件题按明确的结构功能判定。
6. 本地最多保留最近两套题的签名，重新抽取近期重复题；第一关直接从未出现的题干池中选择，其余关设置最多 48 次重抽，避免异常/耗尽历史引起死循环。只看接线板的题不把不可见轮位算作变化。历史不可用时仍正常随机出题。

关卡顺序不随意打乱，避免第一次学习就遇到综合解密；随机的是每关的题目变体、参数组合和答案位置。有限题库允许后续再次出现同一知识点，不承诺无限不重复。

## 状态、交互和模型

- `createSession / submitAnswer / advanceSession`：答题与进度，拒绝跳关，答错可继续，同一关重复点击不重复计章。
- `createMissionState / prepareMission / decodeMissionLetter`：末关独立状态机。先验证起点和接线，再依次执行三次真实按键；反向选择同一对端点也有效。未完成解密不能直接选词；密文输入完后不会多走第四次。
- `src/challenge.js`：DOM 控件、模型命令、焦点、教学动画。单一 `signalProgress` 同步字母读数、当前段和模型亮线；动画中操作按钮用于暂停/继续，逐段按钮不增加按键次数。
- `src/lab-model.js`：复用第二章的三轮、反射器和 26 孔接线板。可旋转、缩放、展开内部；末关点击鼓轮/接线板可定位对应设置。没有改成截图或视频。
- 离开章节暂停动画，返回第三章重新抽题。`dispose` 清理 RAF、事件、几何、材质和纹理。系统减少动态效果时直接显示结果，保留逐关学习能力。WebGL 不可用时字母路线和答题仍可操作。
- 桌面左右分区，观察台、任务和答案区使用深色外框；任务过长时允许面板滚动。手机纵向布局，提供“去观察台/去选答案”按钮；短屏和放大窗口允许页面滚动，避免控件被裁掉。
- 诊断：`window.__BOMBE_QUEST__()` 提供种子、题目签名、当前关、尝试次数、模型资源与渲染状态；它是只读诊断函数，不提供修改关卡的命令。

## 扩充题库

添加 `WORD_BANK` 词卡时，使用 3 个大写 A–Z 字母与中文释义，如 `['ICE', '冰']`，保持词卡唯一。扩展 `PART_BANK` 时保留正确 `target`，只使用 `wiring / rotor / reflector`。增加新题型时同时写题干、三步操作、提示、解释和以 `cipher.js` 为依据的答案计算，并在测试里检查生成参数边界。

本章沿用第二章的 Enigma I–II–III、反射器 B、固定环位 AAA 与一对接线。它用于整合置换、转位和回路知识，不执行完整历史 Bombe 搜索，也不是理论计算模型“图灵机”的程序演示。

## 验证边界

见 `CODE_QUEST_QA.md`。构建、纯算法和 CPU 几何测试分别验证各自范围；它们不能代替真实浏览器的 GPU、排版与交互验收。
