# Bombe 项目 00「战时序章」文本与页面结构

## 范围与依据

- 页面：00「战时序章」，默认路由 `/` 与 `#/history`。
- 当前文案及结构基准：`history-preview.html`。
- 样式与断点：`history-preview.css`。
- 页面增强：`src/history-preview.js`、`src/history-scenes.js`、`src/history-gallery.js`、`src/history-loader.js`。
- 路由与组合：`src/routes.js`、`src/navigation.js`、`page-shell.mjs`。
- 内容背景：`docs/HISTORY_00_COPY.md`、`docs/HISTORY_00_SPEC.md`、`docs/HISTORY_18_ACCEPTANCE.md`。

`HISTORY_00_COPY.md` 和 `HISTORY_00_SPEC.md` 记录了早期七幕方案；当前页面已经扩展为 18 节。涉及实际页面文字时，以 HTML 当前渲染内容为准，不把旧稿中的标题或交互说明当作现行文案。

## 页面结构

```text
00 战时序章
├─ 跳过链接：跳到正文
├─ 全局页眉 masthead
│  ├─ 品牌：译码档案 / 战争、机器与人的故事
│  └─ 展馆导航：战时序章、机械全貌、信号实验室、解密挑战、黎明之前
├─ 主内容 history-main
│  ├─ 01 海上生命线：封面 + 第一节正文
│  ├─ 阅读目录：18 节锚点索引
│  ├─ 章节分隔标记：四段叙事的组间转场
│  ├─ 02–18 历史章节
│  └─ 章节内来源链接
└─ 来源页脚 sources
   ├─ 史料说明与返回开篇链接
   └─ 来源编号及外部资料链接
```

### 页面级布局

| 区域 | 结构与作用 |
| --- | --- |
| 页眉 | 品牌链接返回 00；五个章节链接在各产品页间导航，当前章节由 `aria-current="page"` 标出。 |
| 封面 | 深色海洋主题；左侧为版本、主标题、导语和两个入口，右侧为护航影像、图注与来源；底部有叙事引导和影像载入状态。封面同时承载第 01 节开篇正文。 |
| 阅读目录 | 可展开/收起的原生 `details` 目录，提供 18 节锚点；目录项随阅读位置更新当前章节。 |
| 章节流 | 按历史时间和分析流程组织的四段叙事。章节通常由编号/时间索引、标题、正文、视觉素材和章节来源组成；局部章节使用人物、双栏或收束变体。 |
| 来源页脚 | 说明史料、图像与教学示意的标注方式，列出 S1–S9 来源，并提供返回开篇链接。 |

### 章节组件结构

```text
section[data-history-scene]#章节锚点
├─ .section-index：章节编号 + 时间/主题标签
└─ .section-content
   ├─ header.scene-heading > h2：章节标题
   ├─ .section-prose：叙事正文、补充说明或原生 details
   ├─ .section-visual：照片、图解、示意图或人物资料
   └─ .chapter-reference：本节对应的来源
```

这是常用结构，不是每节都必须具备全部子项。封面节使用 `.archive-cover` 和 `h1`；常规章节使用 `.history-section` 和 `h2`。人物、双栏和最后的入口节通过 `people`、`person-chapter`、`split`、`closing` 等类名控制具体布局。

当前 DOM 中共有 18 个 `[data-history-scene]` 阅读场景；第 01 节是封面型场景，不使用 `.history-section`，所以常规 `.history-section` 数量为 17。阅读目录标记的 18 节与场景总数一致。

## 版式与增强行为

- 桌面常规章节按章节索引、文本和视觉素材构成编辑式图文版面；`split` 章节使用文字与视觉的双栏组合。人物、档案照片、流程图、机器图解和收束章节由不同的章节类名承载。
- 手机断点将双栏内容改为自然纵向阅读；章节索引、正文和素材仍按 DOM 顺序出现。具体断点规则由 `history-preview.css` 管理。
- 页面内容先存在于 HTML。JavaScript 增强阅读位置、章节显现、影像画廊与首屏影像状态；`prefers-reduced-motion` 或缺少 `IntersectionObserver` 时保留静态可读内容。
- 章节锚点由 `src/routes.js` 白名单处理；`#/history` 是显式 00 路由，普通章节锚点用于同页阅读。`src/navigation.js` 负责在 00 与 01–04 之间切换。
- 当前首页由 `page-shell.mjs` 将历史页与交互展馆合成；单独的 `history-preview.html` 是同一历史内容的独立预览入口，不应误认为另一个章节。
