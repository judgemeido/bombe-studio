## 核查结果

1. **级联符合意图。** 末尾同作用域、同等优先级的规则覆盖旧的手机两列目录 grid、链接 width:100% 及旧间距。小屏目录实际成为 nowrap flex 横向滚动容器；旧 grid-template-columns 在 flex 上不生效，不构成冲突。最新 ≤360px 四列规则只作用于展馆导航 `.archive-chapters`，不会把七幕目录重新改回 grid。
2. **响应式无已证实的页面横向溢出。** 本次 headless Edge 在 320、390、700、1050、1060、1100、1101、1440px 视口测量：首页文档 scrollWidth 均等于 clientWidth。320px 页头约106px，390px 页头约108px；具体高度受浏览器字体、滚动条及行高影响，不要求与主代理的104.7/107px逐像素一致。1050/1100px 附近既有 block/flex 切换造成目录高度变化，但未形成裁切或内容不可达。
3. **横滚目录保留原生链接可达性。** 独立预览页390px下，聚焦末项后 Shift+Tab 可到第六幕，容器自动横滚（scrollLeft=304），键盘焦点 outline 为 solid。链接保留 aria-label、原生锚点与已有 focus-visible 样式；未引入需要鼠标才能访问的目录。滚动容器边缘的外扩焦点环可能局部裁切，未观察到完全不可见或无法导航，不列为阻断。
4. **排版规则未扩大泄漏。** 新规则保留 `[data-history-preview]` 作用域；统一横向 padding 不影响其它交互页面。`text-wrap: balance` 作用于场景标题，不支持该属性的浏览器仍回退普通换行；原有小屏字号和更窄断点继续生效。
